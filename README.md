# Make the Judge Smile

One line, at most 200 characters, about a small good thing that happened today — something that would make a reader smile. Entry for the [Make the Judge Smile bounty](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d) on [make.fun](https://make.fun) ($5 USDC, top 3 paid $2/$2/$1).

## The line

> My neighbour left a mango on my doorstep today with a note, 'tree's too generous, help yourself', and I ate it standing in the hallway.

## How it works

`main.ts` (Node 22, stdlib only) reads the line from `line.txt`, checks it is 1–200 characters and not only whitespace, then writes it to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```

## Files

- `main.ts` — the entry program
- `line.txt` — the single line (135 characters)
- `prompt.txt` — the build brief, verbatim
